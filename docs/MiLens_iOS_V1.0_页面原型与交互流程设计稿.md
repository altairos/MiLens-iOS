# MiLens iOS V1.0 页面原型与交互流程设计稿

> 状态说明（2026-08-08）：本文只保留早期产品叙事与战略背景，不再作为页面布局、视觉或 V1 功能范围依据。执行规格见 [../UI-DESIGN.md](../UI-DESIGN.md)，范围以 [adr/0008-v1-scope-decision.md](adr/0008-v1-scope-decision.md) 为准。下文出现的 AI 写真、回忆视频等内容属于早期设想，不代表 V1 承诺。

## 产品核心叙事

一句话：

> 找回手机里被遗忘的它，保存属于你们的一生。

MiLens 不应被定位为普通照片管理工具，而应成为宠物家庭的数字生命档案入口。

---

# 一、整体信息架构

采用 iOS 标准 Tab Bar：

```
首页 | 宠物 | 创作 | 我的
```

---

# Tab 1：首页 Home

定位：

> 今日陪伴入口。

核心内容：

- 今日宠物照片
- 历史回忆
- 成长提醒
- 快速创作入口

示例：

```
早上好

今天的小橘

[今日照片]

来看看它一年前的今天

快速创作：
生日卡 / 回忆视频 / 拼豆 / AI写真
```

目标：

形成日常打开习惯，提高 DAU。

---

# Tab 2：宠物 Pets

定位：

产品核心资产。

展示：

- 宠物头像
- 名称
- 年龄
- 照片数量
- 成长轨迹

示例：

```
小橘

3岁2个月

照片：3280张

成长轨迹

2021 来到家
2022 第一次生日
2023 最喜欢的位置
2024 学会开门
```

进入详情：

- 全部照片
- 幼年照片
- 玩耍
- 睡觉
- 成长时间线

未来可扩展：

- 健康档案
- 疫苗记录
- 体重管理

---

# Tab 3：创作 Create

定位：

商业化入口。

功能：

## AI写真

生成：

- 油画
- 漫画
- 像素风
- 国风

## 回忆视频

自动生成：

“小橘的一年”

## 拼豆图纸

照片转换为像素图纸。

## 宠物卡片

用于：

- 生日
- 纪念日
- 分享

---

# Tab 4：我的

包括：

- MiLens Pro
- 恢复购买
- 主题
- 隐私设置
- 帮助
- 关于

# 二、首次启动流程

## Step 1 欢迎页

文案：

```
记录爱的一生

MiLens 会帮你：

✓ 找到所有宠物照片
✓ 认识你的每一只宠物
✓ 保存成长回忆
```

---

## Step 2 权限说明

强调：

- 照片不会离开设备
- AI分析在本地完成

---

## Step 3 扫描

避免工具化表达。

不要：

“正在分析10000张照片”

改为：

```
正在寻找它的身影...

发现：

🐱 842张猫咪照片
🐶 53张狗狗照片
```

---

## Step 4 创建第一份档案

情绪峰值：

```
我们找到了小橘。

照片：842张

最早记录：
2021年5月1日

看看它的一生
```

---

# 三、付费墙设计

不要首次启动收费。

应在用户产生情感连接后出现。

示例：

```
让这份回忆继续成长

MiLens Pro

✓ 无限宠物档案
✓ AI成长视频
✓ 高级创作模板
✓ 高清导出

免费试用7天
```

# 五、App Store 展示策略

不要展示普通相册。

推荐截图：

1.

2.
AI认识你的每一只宠物

3.
看见它从小到大的变化

4.
创造属于它的作品

5.
隐私保护，照片不离开手机

# 七、V1.0砍功能

暂缓：

- 社区
- 云账号
- 宠物商城
- 健康管理
- 手表App

原因：

第一版应聚焦核心价值。

---

# 八、产品战略判断

MiLens 不应竞争：

- Apple Photos
- Google Photos

真正定位：

宠物数字生命档案。

用户下载理由：

“我想整理宠物照片。”

用户留下理由：

“我想保存它的一生。”

用户付费理由：

“我想创造关于它的作品。”
