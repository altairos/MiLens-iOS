### 5.3 功能走查

1. **首次启动**：空相册 → 点击「开始扫描」→ 授权 Photos → 等待扫描完成弹窗
2. **导入**：扫描完成弹窗 → 点「导入 N 张照片」→ 验证照片出现在网格
3. **大图查看**：点网格照片 → 双击放大 → 捏合 → 平移 → 返回
4. **多选**：工具栏圆形按钮 → 勾选照片 → 返回
5. **分页**：导入 100+ 照片 → 快速滚动到底部 → 验证自动加载更多
6. **取消扫描**：启动扫描 → 点「取消」→ 验证不崩溃、不提交部分结果
7. **质量评分**（P2 增强）：导入照片后 → 通过 Xcode调试器/预览检查 `Photo.qualityScore` 和 `sharpness` 字段是否非零（后台 fire-and-forget，扫描/导入完成后数秒内完成）
8. **重复分组**（P2 增强）：导入 2–3 张相似照片（连拍/裁切版）→ 检查 `Photo.isBest` / `duplicateOf` 字段：其中 1 张 `isBest == true`，其余 `duplicateOf` 指向 best 的 UUID
9. **pHash 精度**（P2 增强）：导入一张清晰照片 + 一张模糊版 → 检查两者 pHash 汉明距离是否 ≤ 8（相似）；再导入一张完全不同的照片 → 检查距离是否 > 16

#### 5.3.1 CLIP / Vision / Core ML 推理走查

10. **Vision 宠物预筛**：准备 10 张宠物照片（猫/狗各 5）+ 5 张非宠物（人物/食物/风景）→ 执行扫描 → 通过 Xcode 调试器检查 `IOSVisionService.detectPets` 返回的 `DetectionBox`：宠物照片命中率、非宠物误判率
11. **CLIP 推理质量**：用同一批照片 → 检查 `ClipInferenceService.detect` 返回的 `ClipDetectionResult`：`isPet` 判定、`species` 分类、`topConfidence` 数值范围（宠物应 >0.20，非宠物应 <0.20）
12. **分割蒙版**：选一张清晰的宠物照片 → 调用 `IOSVisionService.segmentSubject` → 检查返回的 `SegmentationResult.mask` 数据非全零、蒙版 bbox 尺寸与原图一致
13. **embedding 维度**：检查 `ClipDetectionResult.embedding` 为 512 维且已 L2 归一化（范数 ≈ 1.0）
14. **降级链**：从 bundle 临时移除 `CLIPVisionEncoder_int8.mlmodelc` → 重启 App → 验证 `ClipInferenceService.create` 返回 nil，扫描降级到纯 Vision 预筛（不崩溃）
15. **输出张量选择**：检查 `selectOutputEmbedding` 在真实 Core ML 输出上选择了名为 `image_features` 的输出（通过 diagnostics 日志确认），而非误选其他输出
16. **计算单元验证**：在真机上检查 Core ML 是否实际使用 Neural Engine（Xcode → Debug Navigator → Energy / Metal）
