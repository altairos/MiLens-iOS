# 红包封面开发计划

最后更新：2026-08-24

关联文档：[DESIGN.md](../DESIGN.md)、[PLAN.md](../PLAN.md)、[UI-DESIGN.md](../UI-DESIGN.md)

## 1. 产品目标与边界

红包封面不是“选择照片后自动套模板”，而是一个轻量、可恢复的红包创作工作室。用户先选择风格模板，再确认宠物照片和抠图结果，最后按需要添加配饰与文本，并在导出前看到红包在分享语境中的效果。

V1 只负责生成符合平台规格的封面素材、提供中性使用场景预览、保存到系统相册或通过系统分享分享，并提供上传平台的操作说明。

V1 不负责登录或调用微信账号，不代替用户上传、审核或发布，不精确复刻微信客户端的界面、商标、图标或完整视觉规范，也不上传用户照片或调用云端 AI 图片生成。

规格基线继续复用 `MiLensKit` 的 `WeChatRedPacketSpec`：封面图 957×1278、文件不超过 500KB；故事图、Logo 和平台上传流程另按实际实现逐项验证。

## 2. 用户主流程

```text
创作首页 → 选择模板 → 选择/更换照片 → 本地抠图与质量检查
→ 确认抠图 → 红包工作室编辑
   ├─ 调整宠物
   ├─ 添加/调整配饰
   ├─ 添加/编辑文本
   └─ 智能优化
→ 导出预览 → 分享语境模拟 → 保存/系统分享 → 上传平台指引
```

### 2.1 模板选择

首期制作四套风格模板。模板选择页展示缩略图、风格名、默认宠物示例和文本风格，不在此页直接生成不可编辑成品。

模板必须是结构化资源，而不是单张背景图。每个模板至少包含：

- `templateID` 和 `revision`；
- 背景层、前景层资源；
- 默认宠物位置、缩放和旋转；
- 安全区和风险区；
- 默认文本样式与位置；
- 推荐配饰分类；
- 模板缩略图和无宠物预览图。

切换模板时保留照片、抠图结果和文本内容；配饰位置、默认样式和模板专属排版按新模板重新计算，并在必要时提示用户。

### 2.2 照片与抠图

- 默认带入上一页的照片，并提供“换一张照片”；
- 抠图由设备端 Vision 服务完成，支持取消、重试和失败说明；
- 抠图失败时不以中心裁切或原图覆盖伪装成功；
- V1 先不做手动修边，但数据结构保留 mask / matte 的后续扩展位置。

换照片时默认保留模板、文本内容和配饰；宠物图层尽量保留原位置与缩放。如果新照片主体比例差异过大，再执行模板适配并提示用户。

## 3. 红包工作室编辑器

### 3.1 图层结构

渲染顺序固定为：

1. 背景层：模板固定、不可选择；
2. 宠物抠图层：可移动、缩放、旋转；
3. 配饰 / 文本层：每个对象独立选择和编辑；
4. 前景层：模板固定、不可选择。

背景与前景属于模板层，配饰和文本虽然都属于用户内容，但必须分别建模，不能合并为一张可编辑图片。

编辑坐标统一使用 957×1278 设计画布坐标，不使用屏幕坐标。现有 `EditorLayer`、`EditorLayerGeometry` 可以复用几何语义，但红包应提供独立的模板、草稿和导出模型。

### 3.2 画布交互

- 单指拖动移动当前图层；
- 双指缩放和旋转；
- 点击空白处取消选中，重叠元素按视觉层级选择；
- 选中后提供删除、置中、恢复默认；
- 拖动时显示中心线、边缘线和对象对齐线；
- 限制图层数量与缩放范围；
- 安全区遮罩只用于编辑提示，不参与最终导出。

画布下方只保留三个等宽内容通道：伙伴、配饰、祝福语，不显示步骤编号。模板切换、更换照片和画面检查收进顶部更多菜单；删除、旋转、置中等动作放到当前图层上下文操作中。

### 3.3 配饰与文本

配饰支持多个独立图层，可拖动、缩放、旋转、删除和调整层级。建议 V1 限制最多 3–5 个，并按新年、招财、花卉、宠物主题等分类。

文本内容与文本风格分离：用户可以改内容，模板提供预置风格。V1 支持添加、删除、隐藏、修改内容、拖动、缩放、旋转和预置风格切换；暂不开放任意字体、复杂描边和自由阴影参数。建议提供“新年喜庆、温柔手写、极简印章、金色祝福、宠物昵称”等风格，并限制文本长度。

## 4. 智能检测与微调

智能能力默认是“建议”，不静默改图。质量报告至少覆盖：

| 项目 | 检测内容 | 建议动作 |
|---|---|---|
| 清晰度 | 原图分辨率、主体有效像素、模糊程度 | 换图或轻微锐化 |
| 亮度 | 主体过暗、过曝、背景与主体亮度差 | 提亮主体、调整对比度 |
| 构图 | 主体过小、被裁切、偏离安全区 | 放大、移动、重新适配 |
| 抠图 | 边缘破碎、透明区域异常、主体不完整 | 重试抠图或换图 |
| 可读性 | 文本与背景对比度、文本遮挡风险 | 更换风格或移动 |

“智能优化”一次最多执行轻微亮度/对比度/锐度调整、宠物位置适配、文字安全区移动，以及模板预置的描边或阴影。优化前后可切换并可撤销，文案使用“建议优化”“已为你调整”，不承诺平台审核通过。

## 5. 草稿与数据模型

红包应保存为可恢复草稿，而不是只保存最终 PNG：

```swift
struct RedPacketCoverDraft {
    var id: UUID
    var templateID: String
    var templateRevision: Int
    var sourcePhotoID: UUID?
    var layers: [RedPacketLayer]
    var qualityReport: RedPacketQualityReport?
    var createdAt: Date
    var updatedAt: Date
}
```

`RedPacketLayer` 至少区分模板背景、宠物抠图、配饰、文本和模板前景。资源保存为文件路径或资源 ID，抠图保存为 matte / mask 路径，不把 `CGImage`、`UIImage` 或大位图写入 SwiftData。

建议先使用本地草稿目录 + JSON 验证编辑闭环；需要跨启动、多个草稿和删除联动后，再增加 SwiftData `@Model`。若进入 SwiftData，必须同步更新 VersionedSchema、迁移计划、Repository 和测试。

## 6. 导出页与分享语境预览

你提供的“模拟聊天窗口”方向是合适的。它让用户确认的不是单独一张大图，而是“封面作为红包缩略图或分享卡片出现时大概是什么样”。这比单独放封面和分享按钮更接近真实使用场景。

### 6.1 推荐结构

导出页可分为两段：

上段是成品检查：封面大图、尺寸/格式/文件大小、安全区和水印状态，以及“重新编辑”。

下段是分享前预览：中性聊天窗口背景、头像、红包分享卡片（封面缩略图、祝福标题、宠物昵称）、模拟红包状态，以及“保存到相册”和“分享”两个主要动作。

“保存到相册”作为稳定主动作；“分享”实际接系统分享面板，让微信在已安装时自然出现，不假设微信已安装，也不直接调用微信私有接口。

### 6.2 对示例图的取舍

可以保留“头像 → 红包卡片 → 保存说明 → 行动按钮”的核心关系，但建议：

1. 不使用微信 Logo、微信绿色品牌色、真实聊天顶部栏、真实微信图标或像素级红包卡片复刻；
2. 将“保存后这样用”改成 MiLens 自己的说明，例如“保存到相册后，在微信红包封面页面选择自定义封面即可”；
3. 按钮不写成“分享到微信”，只写“分享”

预览上标注“场景预览”或“示意效果”。原 `WeChatRedPacketMockView`（无调用方死代码，已删除）的四场景方案已收敛为 `RedPacketScenePreview` 的中性三场景（聊天横幅/拆红包/红包列表），聊天横幅即上述卡片形态。拆红包场景只近似还原必要的合成关系：MiLens 导出的 957×1278 自定义封面作为 3:4 后景，微信客户端自带的橙红前景与“开”按钮作为独立前景叠加；后两者仅用于场景预览，绝不写入导出素材。

### 6.3 导出动作

1. 用同一份草稿渲染封面和预览缩略图；
2. 校验 957×1278、格式和文件大小；
3. PNG 不超限时优先使用，超限时按 JPEG 降级链编码；
4. 保存相册与系统分享使用同一份已校验数据；
5. 导出成功后提供可见反馈，并允许进入上传指引。

不要让预览图和最终导出图使用两套排版逻辑，否则聊天缩略图可能与最终文件不一致。

## 7. 分期开发任务

### Phase 0：规格与资源准备

- [x] 冻结四套模板的视觉方向、命名和安全区；
- [x] 制作背景 / 前景 / 配饰 / 文本风格资源；
- [x] 明确资源尺寸、透明通道、命名和版本策略；
- [x] 确认导出页中性聊天预览稿；
- [x] 为模板、配饰、文字风格建立纯数据模型。

验收：四套模板都能在没有用户照片时展示默认预览；资源有稳定 ID 和 revision。

### Phase 1：单模板最小闭环

- [x] 一套模板；
- [x] 选择 / 更换照片；
- [x] Vision 抠图、取消、失败重试；
- [x] 宠物图层拖动、缩放、旋转；
- [x] 一种文本风格；
- [x] 草稿 JSON 保存与恢复；
- [x] 957×1278 导出、相册保存、系统分享。

验收：用户可以完成一次编辑、退出、恢复和导出，原图不被覆盖。

### Phase 2：四模板与完整编辑能力

- [x] 四套模板切换；
- [x] 配饰目录与多个配饰图层；
- [x] 文本编辑与预置风格切换；
- [x] 安全区、对齐线、删除、置中、恢复默认；
- [x] 图层选择和层级调整；
- [x] 撤销 / 重做；
- [x] 模板切换后的内容保留策略。

验收：每类图层都可独立操作，切换模板或照片不会破坏已有内容。

### Phase 3：质量建议与智能优化

- [x] 清晰度、亮度、构图和抠图结果检测；
- [x] 文本可读性与安全区检测；
- [x] 质量报告 UI；
- [x] 一键智能优化；
- [x] 优化前后对比和撤销；
- [ ] 真实照片集校准阈值。

当前实现不再使用固定占位值：清晰度读取原图分辨率与 256px 采样图的 Laplacian 方差；亮度读取抠图主体（失败时回退原图）的平均亮度、阴影剪切和高光剪切；构图使用旋转后图层外接框计算画布可见比例与安全区覆盖率；抠图使用 alpha 蒙版的前景占比、最大连通域、边界接触率和边缘粗糙度。解码、蒙版合成与像素采样在后台任务执行，抠图 RGBA 合成缓冲最大边限制为 2048px；失败会生成可诊断的问题项，不用默认“通过”值兜底。

验收：检测失败可诊断、优化可撤销，且不把建议描述成平台审核保证。

### Phase 4：导出语境与平台引导

- [x] 聊天红包卡片预览；
- [x] 保存到相册和分享按钮（系统分享面板）；
- [x] 系统分享面板接线；
- [x] 封面、缩略图、分享语境共用渲染结果；
- [x] 规格检查结果和失败原因；
- [x] 上传平台五步指引；
- [x] 水印与 Pro 权益规则确认。

验收：用户能理解成品用途，能保存或分享，且不会误以为 App 已经替其发布红包封面。

## 8. 架构落点

建议新增或扩展：

```text
MiLensKit/Sources/MiLensKit/RedPacket/
├── RedPacketTemplate.swift
├── RedPacketLayer.swift
├── RedPacketDraft.swift
├── RedPacketLayoutLogic.swift
├── RedPacketMaskQualityLogic.swift
├── RedPacketQualityLogic.swift
└── RedPacketExportLogic.swift

MiLens/Views/Create/RedPacket/
├── RedPacketTemplatePickerView.swift
├── RedPacketPhotoPickerView.swift
├── RedPacketWorkshopView.swift
├── RedPacketCanvasView.swift
├── RedPacketInspectorView.swift
├── RedPacketExportView.swift
└── RedPacketUploadGuideView.swift
```

App 层的 `Services/Editor/RedPacketImageQualityAnalyzer.swift` 负责图片解码、亮度采样、清晰度复用、蒙版应用与透明边缘裁切；纯阈值和几何判断留在 MiLensKit，便于用合成输入稳定测试。

App 层 View 只负责渲染和事件转发；模板适配、安全区判定、图层命中、缩放边界、质量建议和导出决策下沉到 `MiLensKit` 纯逻辑。Vision、Photos、ImageRenderer、相册保存和系统分享继续通过 Service / Platform protocol 注入。

## 9. 验证要求

纯逻辑 XCTest 覆盖模板完整性、图层默认位置与边界、拖动/缩放/旋转/命中、安全区、模板切换与照片替换保留策略、文本长度与可读性、质量建议、智能优化、导出规格和文件名。

App 与真机验证覆盖 iPhone/iPad、深色模式、Dynamic Type、VoiceOver、Vision 抠图取消/失败、高分辨率内存峰值、相册权限拒绝、系统分享不可用、真实平台规格校验，以及场景预览与最终导出一致性。

Windows 只能完成文档、纯逻辑和静态检查；Swift 编译、XCTest、模拟器、真机和平台上传验证必须在 macOS / Xcode 执行。

## 10. 当前未决事项

- 四套模板是否全部免费，还是首套免费、其余 Pro；
- 配饰是否按分类做 Pro 门控；
- 封面故事图是否随 V1 一起提供编辑能力；
- 聊天语境预览是否只保留一个主场景，还是继续四场景切换；
- 是否允许保存多个红包草稿；
- 真实平台对 PNG / JPEG、色彩空间和压缩质量的最终规则；

默认建议：四套模板都可预览，首套模板与基础文本能力免费；高级模板、配饰包和无水印高清导出再接入 Pro。导出页统一使用“分享”，实际走系统分享面板并明确说明。
