## 2. 模板实装明细（已实装的部分）

### 2.1 伙伴纪念卡（[PetCardTemplate](../MiLensKit/Sources/MiLensKit/Types/PetCardTemplate.swift)，4 套）

[PetCardArtwork](../MiLens/Views/Create/PetCardArtwork.swift) 按 `template` 分支排版（360×450 基准，导出 1080×1350），4 套全部实装（2026-08-15 Figma 版式重制）：

| 模板 | 风格 | 权益 |
|------|------|------|
| museum 博物馆典藏 | 白底纸纤维 + 竹拓墨叶 + 朱砂藏印 + 季节字 | 免费 |
| binding 私人装帧 | 铜装订线 + 布纹 + 护页衬纸 + 书脊织纹压印 | Pro |
| gallery 现代画廊 | 满版照 + 黑带丝网半调 + 朱砂导轨 + Marker | Pro |
| darkroom 夜间暗房 | 安全灯 + 银盐颗粒 + 胶片齿孔 + 曝光轨样片 | Pro |

纹理组件（[CardTextures](../MiLens/Views/Create/CardTextures.swift)）用固定 seed 的 mulberry32 伪随机绘制，预览与 ImageRenderer 导出逐像素一致；画布色值固定 hex（CardInk），不受系统深浅色影响。

### 2.2 宠物名片（[BusinessCardTemplate](../MiLensKit/Sources/MiLensKit/Types/BusinessCardTemplate.swift)，4 套）

[BusinessCardArtwork](../MiLens/Views/Create/BusinessCard/BusinessCardArtwork.swift) 按 `template` 分支排版（720×450 基准，导出 1440×900，16:10 横版），4 套全部实装（2026-08-15 Figma 版式重制）：

| 模板 | 风格 | 权益 |
|------|------|------|
| museum 博物馆典藏 | 左侧竖裁照片 + 藏书脊分隔 + 两段式字段 + 纸纤维/竹拓 + MILENS ID | 免费 |
| binding 私人装帧 | 铜装订线 + 护页衬纸 + 内联字段 + 书脊织纹 | Pro |
| gallery 现代画廊 | 黑场半调 + 满版照 + 朱砂导轨 + 铜底 ID Block | Pro |
| darkroom 夜间暗房 | 安全灯 + 银盐颗粒 + 样片齿孔 + 曝光轨 | Pro |

字段派生（[PetBusinessCardLogic](../MiLensKit/Sources/MiLensKit/BusinessCard/PetBusinessCardLogic.swift)）：
- **MILENS ID**：名字拼音首字母（大写）+ 生日 MMDD，以「—」连接（如「小满」5/21 生 → `XM—0521`）；缺生日回退建档日期；非中文名回退原名首字母；均无法解析时不渲染该行。
- **照护人**：主人称呼前缀由「铲屎官：」改为「照护人｜」。
- 另派生身份行（物种 · 年龄 · 性别）、季节行（YYYY · 春/夏/秋/冬）、拍摄时间（YYYY.MM.DD）。
