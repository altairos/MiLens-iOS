## P1 可靠性遗留（先修）

- [ ] `OnboardingViewModel` 仅在 `result.completedSuccessfully` 时保存扫描游标；错误或取消不得推进增量基线。
- [ ] 明确“重建本地数据”对 `Documents/MiPhotos` 沙盒副本的处理：要么保留并建立恢复策略，要么在确认文案中明确其也会被清除，避免与当前“仅清除记录”表述不一致。
- [ ] 编辑保存清理旧文件时，数据库引用查询失败应保守保留旧文件，不能将查询失败等同于“无引用”。

## 真机功能验收（Mac + iPhone，iOS 17+）

- [ ] 首次启动：Photos 授权、引导扫描、取消、错误提示、重试。
- [ ] 导入闭环：真实照片加载、缩放副本落盘、重启后仍可读、重复导入被跳过。
- [ ] 5000+ 大图库：流式扫描、分页滚动、取消响应时间、前后台切换行为。
- [ ] Vision 宠物预筛：猫/狗召回率、人物/食物/风景误报率、单张延迟。
- [ ] CLIP 精筛：真实模型加载、`image_features` 输出选择、宠物/非宠物阈值、降级链。
- [ ] 主体分割：蒙版非空、bbox/尺寸对齐、毛发边缘质量。
- [ ] 质量评分与重复分组：清晰/模糊、连拍/裁切、完全不同照片的 pHash 距离与 best 标记。
- [ ] 大图查看：双击、捏合、平移、下滑关闭、横竖屏和深色模式。
- [ ] 通知与后台：生日/领养日年度提醒、时光机每日提醒、拒绝授权后的恢复路径。
