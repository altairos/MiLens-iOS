## P1 可靠性遗留（已收口 2026-08-09）

- [x] `OnboardingViewModel` 仅在 `result.completedSuccessfully` 时保存扫描游标——`startScan` 收尾按 `ScanResult.completedSuccessfully` 判定，失败/取消不保存，`skipScan` 也不推进基线；测试 `OnboardingViewModelTests.testScanSuccessSavesCursor` / `testScanFailureShowsErrorAndDoesNotComplete`（提交 ba434c4/b60749c）。
- [x] “重建本地数据”对 `Documents/MiPhotos` 沙盒副本的语义定案：选择「确认文案明确清除范围」方案——`DatabaseRecoveryView` 主文案与二次确认弹窗均明确提示「同时删除沙盒中已保存的照片副本（导入/编辑产物）」，`AppDependencies.destroyPersistentStore` 注释同步说明重建后启动孤儿审计会连带清理无 DB 记录的文件（提交 9cfdf20/b60749c）。
- [x] 编辑保存清理旧文件的保守策略——`MediaLifecycleService.saveEditedPhoto` 中 `getPhotoByURI` 引用查询失败时 `stillReferenced = true` 保守保留旧文件，不得按“无引用”删除；测试 `MediaLifecycleServiceTests.testSaveEditedPhotoKeepsOldFileWhenReferenceQueryFails`（提交 9cfdf20/b60749c）。
